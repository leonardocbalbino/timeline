    Como funciona

    Da galeria bagunçada a uma cronologia que qualquer pessoa entende.

    1. 01

      Crie um processo

      Um para cada caso: trabalhista, família, consumidor, condomínio. Com o número do processo, se já tiver.

    2. 02

      Envie os arquivos

      Arraste vários de uma vez. A data e a hora são sugeridas pelo nome do arquivo (WhatsApp, prints, câmera).

    3. 03

      Descreva e destaque

      Diga o que cada prova demonstra, quem está envolvido e marque as mais importantes.

    4. 04

      Entregue ao advogado

      Relatório para imprimir ou salvar em PDF, pacote ZIP com os originais ou um link somente leitura.

    Dúvidas

    Perguntas frequentes

    O hash garante que a prova vai ser aceita?{{ icon('chevron-down') }}

    Não existe garantia de aceitação: quem decide é o juiz. O hash SHA-256 ajuda a demonstrar que o arquivo apresentado é exatamente o mesmo que foi enviado ao sistema naquela data, porque qualquer alteração muda o código. Converse com seu advogado sobre a melhor forma de apresentar as provas.

    Meus arquivos ficam públicos?{{ icon('chevron-down') }}

    Não. Os arquivos só são entregues a quem entrou na sua conta ou a quem tem o link somente leitura que você gerou. Você pode revogar o link a qualquer momento, e cada acesso fica registrado.

    O sistema altera ou comprime meus arquivos?{{ icon('chevron-down') }}

    Não. O arquivo é guardado exatamente como foi enviado, e o download devolve o original. Por isso o hash continua o mesmo.

    Que tipos de arquivo posso enviar?{{ icon('chevron-down') }}

    Imagens (prints, fotos), áudios (inclusive .opus do WhatsApp), vídeos, PDFs e textos. Cada envio aceita arquivos grandes, de até 4 GB.

    Como funciona o pagamento do Pro?{{ icon('chevron-down') }}

    Dentro da conta, em “Plano”, você gera um Pix com QR Code ou copia e cola. Depois de pagar, clique em “Já paguei”. Assim que o pagamento é confirmado, o Pro é liberado pelo período escolhido. Não há renovação automática.

    E se eu parar de pagar?{{ icon('chevron-down') }}

    Sua conta volta para o Free. Nenhuma prova é apagada: você só fica com os recursos e limites do Free até renovar.

    Meu advogado precisa criar conta?{{ icon('chevron-down') }}

    Não. No Pro, você gera um link somente leitura do processo e envia para ele. Pelo link dá para ver a linha do tempo, abrir o relatório e baixar os arquivos.
